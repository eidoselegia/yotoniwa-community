# Yotoniwa / 夜灯庭 — Community

A tiny place to do absolutely nothing. 给疲惫的人一处可以停留的在线庭院。

**Play / 免费试玩:** https://daydayplay.app/

This is the public feedback and contribution-planning repository, not the game's source repository. The game source remains private for now. No open-source software license has been granted here. This repository contains no production credentials or player records.

这里是公开反馈与共建任务区，不是源码仓库；游戏源码暂未公开。欢迎手机体验反馈、语言校对与原创美术提案。维护者审核后才会采用，不接受直接修改线上网站。

## Start here / 从这里开始

- Browse **Issues** labelled `good first issue` or `help wanted`.
- Comment on an issue before starting; agree on scope first.
- Report your device, browser, reproduction steps, and expected vs. actual behavior.
- Avoid posting personal information, credentials, private logs, copyrighted music or commercial assets.
- This is voluntary collaboration, not a paid job advertisement. Any paid work requires a separate agreement.

## What the prototype currently is

A free browser garden with a daily note, scenery, avatar gestures and room-based encounters. Simulated visitors are labelled separately from connected players. It is an early prototype; loading speed and device compatibility need testing. No claims are made about popularity or guaranteed capacity.

## Contribution process

1. Choose one small issue and leave a comment.
2. Agree on the proposed change and acceptance criteria.
3. Share feedback or an original proposal. See [CONTRIBUTING.md](CONTRIBUTING.md).
4. The maintainer reviews, tests and decides what ships.

Source-code pull requests are not currently available. Do not upload assets until their origin and permission to use them are agreed. Visual submissions are not automatically licensed to the project just because they are posted here.

## Updates

Use GitHub **Watch** to follow this repository. New reports, discussion on issues, and adopted contributions are visible here. A contribution is not promised for release merely because it has been submitted.
