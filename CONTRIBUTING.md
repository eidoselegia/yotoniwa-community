# Contributing / 参与共建

Thanks for helping make this little place more welcoming. 请从一个小问题开始，不要先投入数天重做整个项目。

## Feedback

Include device model, OS/browser version, network type (Wi-Fi/mobile), steps, expected result, actual result, and an optional screenshot. Remove account names, personal messages and other private information before sharing.

## Translation

Suggest short, friendly English or Japanese UI text with the original Chinese beside it. Explain any joke or cultural nuance. Do not promise features or change product rules through translation.

## Art proposals

Start with an image or sketch, not a large downloadable asset. State whether the work is original and whether third-party or AI-generated material was used. Do not submit copyrighted characters, commercial game extracts, recordings or unlicensed textures. Attribution and permitted uses must be explicitly agreed before integration. No automatic transfer of ownership occurs here.

## Review and release

The maintainer decides scope and release timing. Proposals should preserve mobile performance and the quiet atmosphere. Accepted work will receive agreed attribution; submission alone does not guarantee adoption or payment.

Never request or share Cloudflare/GitHub passwords, production access, tokens or player data. For a suspected security issue, report a non-sensitive description first and ask the maintainer for a private channel; do not post exploit details or exposed secrets publicly.
